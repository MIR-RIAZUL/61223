## RIAZUL // DEadEnD — Anti-Gravity Portfolio
> Bleeding-edge spatial computing portfolio built with Next.js App Router (Turbopack), Rust-powered Rapier WASM 3D zero-gravity physics, Three.js WebGPU, and real-time GitHub telemetry.

### Tech Stack
- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS v4 (Ultra-Dark Space Theme `#050508`)
- **Physics**: `@react-three/rapier` (Rust Rapier 3D WebAssembly zero-g engine)
- **3D Graphics**: `three`, `@react-three/fiber`, `@react-three/drei`
- **Animations**: `framer-motion`, `gsap`
- **Telemetry**: Server-Sent Events (SSE) & GitHub Webhook streaming

### Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the anti-gravity viewport, or [http://localhost:3000/admin](http://localhost:3000/admin) for the admin matrix.
